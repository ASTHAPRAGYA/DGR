# SRI1PL Solar DGR Dashboard

Interactive Solar Power Plant Daily Generation Report (DGR) analytics dashboard.

The dashboard allows the user to upload an Excel or CSV Daily Generation Report and automatically generate interactive performance graphs.

---

## Dashboard Features

The dashboard provides:

- Plant Availability (PA)
- Performance Ratio (PR)
- Annual Energy Yield (AEY)
- GHI
- GII / POA
- Measured Generation vs Actual Generation
- Interactive charts
- Date-range filtering
- Custom date selection
- Excel DGR upload
- CSV upload
- Drag-and-drop file upload
- Automatic DGR column detection
- Local browser-based data processing
